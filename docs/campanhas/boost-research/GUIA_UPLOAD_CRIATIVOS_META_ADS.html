Como colocar a versão Feed e a versão Stories no lugar certo no Gerenciador de Anúncios

Os dois slots de mídia

Na tela de criação do anúncio, a seção "Configuração do criativo" tem dois slots separados:

🖼️
Feeds
Feed do Facebook, Feed do Instagram, Marketplace, Explorar
Ebook X - CRIATIVO Y.png
1080 × 1350 (4:5)
↕
📱
Stories, Status e Reels, Resultados da pesquisa
Stories FB/IG, Reels FB/IG, Pesquisa IG
Ebook X - CRIATIVO Y - Storys.png
1080 × 1920 (9:16)

O que acontece se errar

Errado — Só 1 imagem
Feed OK
Cortado!
Se subir só a versão Feed, nos Stories ela fica com barras pretas ou cortada. Perde impacto e parece amador.
Correto — 2 imagens
Feed 4:5
Story 9:16
Cada posicionamento recebe o criativo otimizado para ele. Feed ocupa máximo de tela, Stories usa tela cheia.

Passo a passo

Ir ao nível de Anúncio
Na campanha, navegue até o anúncio específico. A configuração de criativos fica no nível do anúncio, não do conjunto.
Clicar em "Editar" ao lado de "+ Mídia"
Na seção "Configuração do criativo", você verá os dois slots: Feeds e Stories.
Upload no slot "Feeds"
Clique no slot Feeds → Adicionar mídia → Upload → selecione o arquivo SEM "Storys" no nome (ex: Ebook 1 - CRIATIVO 1.png).
Upload no slot "Stories, Status e Reels"
Clique no slot Stories → Adicionar mídia → Upload → selecione o arquivo COM "Storys" no nome (ex: Ebook 1 - CRIATIVO 1 - Storys.png).
Conferir preview
No painel direito, clique em "Prévia avançada" e alterne entre Feed e Stories. Confirme que cada um mostra o criativo correto.
Preencher copy do anúncio
Texto primário + Headline + Descrição do link + CTA (Baixar) + URL de destino + UTMs.
Dica: Como identificar o arquivo

Sem "Storys" no nome = versão Feed (4:5) → vai no slot "Feeds"
Com "Storys" no nome = versão Stories (9:16) → vai no slot "Stories, Status e Reels"

Erros comuns a evitar

1. Subir só uma versão

Se colocar só o Feed, os Stories ficam com barras pretas. Se colocar só Stories, o Feed fica cortado. Sempre subir as duas versões.

2. Usar "Mídia relacionada" como slot principal

A seção "Mídia relacionada" que aparece embaixo é uma sugestão do Meta para adicionar MAIS variações ao Advantage+. Os slots corretos de posicionamento são os de cima: "Feeds" e "Stories, Status e Reels".

3. Inverter os arquivos

Arquivo sem "Storys" no nome = Feed. Arquivo com "Storys" = Stories. Se inverter, o criativo fica esticado/comprimido.

4. Não conferir a prévia

Sempre clicar em "Prévia avançada" (não apenas "Prévia do anúncio") para ver como fica em CADA posicionamento antes de publicar.

Checklist pré-upload (por anúncio)

  • Versão Feed (4:5) no slot "Feeds"
  • Versão Stories (9:16) no slot "Stories, Status e Reels"
  • Preview Feed conferido (Prévia avançada)
  • Preview Stories conferido (Prévia avançada)
  • Texto primário preenchido (copy)
  • Headline do anúncio preenchido
  • Descrição do link preenchida
  • CTA selecionado: "Baixar"
  • URL de destino = LP do e-book
  • UTMs configurados (source, medium, campaign, content)
  • Disclaimer no texto: "Investimentos em criptoativos envolvem riscos."
