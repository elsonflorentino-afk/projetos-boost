## 2. DNA Visual — Referência obrigatória

Os criativos C8 devem seguir o mesmo padrão visual das campanhas C4 e C7 que performaram bem. Não reinventar.

### Cores exatas

| Elemento | Hex | Onde usar |
|----------|-----|-----------|
| Fundo principal | **#12191D** | Background (NÃO usar preto puro #000) |
| Destaque teal | **#03E4D0** | Palavras-chave no headline (1-2 palavras por frase) |
| Texto headline | **#FFFFFF** | Headlines em branco bold |
| Texto body | **#F1F1F2** | Texto de apoio (off-white, mais leve) |

### Tipografia

- **Headlines:** Bold Italic, UPPERCASE, centralizado
- **Body:** Regular, sentence case, centralizado
- **Família:** Inter, Sora ou Neue Haas Grotesk (o que estiver disponível)

### Layout

```
┌────────────────────┐
│                    │
│   FOTO ANDRÉ       │  ← 50-65% superior
│   (com fundo        │
│    original)        │
│                    │
│ ▓▓ gradiente ▓▓▓▓ │  ← transição suave foto → fundo
│                    │
│   HEADLINE BOLD    │  ← palavras-chave em teal
│   ITALIC UPPER     │
│                    │
│   body text 2-3    │
│   linhas max       │
│                    │
└────────────────────┘
```

### Regras visuais inegociáveis

- Foto do André = metade superior, COM fundo original (NÃO recortar/remover fundo)
- Gradiente escuro suave fundindo foto com fundo #12191D (NUNCA corte reto)
- SEM logo no criativo (a marca aparece no nome da página do Facebook)
- SEM botão de CTA no criativo (o Meta coloca automaticamente)
- SEM bullets, SEM ícones, SEM emojis
- SEM bordas, SEM molduras
- Headline máx 2 linhas
- Body máx 3 linhas

## 7. O que NÃO fazer

- NÃO usar preto puro (#000000) como fundo — usar #12191D
- NÃO recortar o André do fundo — manter o fundo original da foto
- NÃO usar corte reto entre foto e texto — sempre gradiente suave

- NÃO colocar botão de CTA no criativo
