Perguntas frequentes

É realmente gratuito?

Sim. A análise inicial não tem custo. Se fizer sentido seguir, apresentamos como funciona a consultoria. Se não, a conversa já foi útil.

Preciso ter um patrimônio mínimo?

A análise é para investidores com patrimônio a partir de R$ 50 mil em cripto ou R$ 200 mil no mercado tradicional. Se seu perfil for diferente, informamos com transparência.

Vocês vão me vender algo?

Não há script de vendas. O objetivo da conversa é analisar sua carteira. Se a consultoria fizer sentido para seu perfil, explicamos como funciona. Se não fizer, dizemos isso com clareza.
